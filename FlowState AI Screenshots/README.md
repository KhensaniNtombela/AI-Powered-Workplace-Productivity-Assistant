The users can sign up and/or login to access the dashboard where most of the features can be explores.

The AI tools page provides an overview of the AI tools implemented in the system and available for the user to explore.

On this page, the user can explore the AI tool that can assist them with generating emails. An interesting feature her is how the tool has an option to set the tone and audience on the receiving end.
